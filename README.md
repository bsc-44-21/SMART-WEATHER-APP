🌾 Smart Weather App

Smart Weather App is a comprehensive, AI-powered agricultural mobile application built with Flutter. Designed specifically for modern farmers and agricultural enthusiasts, it bridges the gap between hyper-local weather forecasting and actionable farm management.

By integrating real-time weather data with AI-driven insights, the app helps farmers make informed decisions to optimize crop yields, manage daily farming tasks, and mitigate risks from adverse weather and pests.

✨ Key Features

Hyper-Local Weather Forecasting: Powered by the Open-Meteo API, providing highly accurate, real-time current conditions, hourly forecasts, and extended daily forecasts.

AI-Powered Agricultural Advice: Integrated AI engine that analyzes weather patterns and farm data to deliver tailored recommendations (e.g., optimal planting times, irrigation needs).

Smart Pest Detection & Alerts: Proactive notifications alerting farmers to potential pest threats based on current environmental conditions, complete with AI-generated mitigation strategies.

Farm & Plot Management: Easily register and manage multiple farm plots, track total field area (in hectares), and monitor conditions on a per-plot basis.

Activity Logging: A built-in digital ledger to record daily farm tasks, events, and milestones, keeping your farm's history organized in one place.

Premium Subscriptions: Seamless integration with PayChangu for processing premium subscriptions, unlocking advanced analytics and extended weather forecasting.

Modern & Intuitive UI: A beautifully crafted interface utilizing Google Fonts, Lucide Icons, and smooth gradients to ensure a premium user experience.

🛠️ Tech Stack

Frontend: Flutter & Dart

Backend & Auth: Firebase (Authentication, Firestore)

State Management: Provider

Weather API: Open-Meteo

Payments: PayChangu

AI Integration: Google Gemini API
